# DSSR RNA studio 1.8.0

现在只有一个窗口：左侧结构分类、条目和摘要，右侧 2D 编辑画布。
仍是单个 Python 运行文件，统一白底，不需要 Java/Jmol。

本次新增彩色碱基字母、一维序列、默认矩形框选和可收起的 2D 面板。
标准、圆形、线性和 legacy radiate 布局及备用路径、果冻和自由扫选保留。

## 安装

1. 安装支持 Qt 的 PyMOL，并单独安装 X3DNA-DSSR。
2. 将 `x3dna-dssr` 放入 PATH，或在插件 **Settings**
   中填写完整路径。DSSR 不在 ZIP 内。
3. 用 PyMOL 的 **Plugin → Plugin Manager → Install New Plugin** 安装
   `dssr_select.py`，重启 PyMOL。
4. 加载本地 PDB/CIF，或输入：

```text
fetch 1ehz, async=0
dssr_gui
```

首次打开会分析已加载的分子。之后切换对象、选择表达式或 state，点击
**Analyze**，同时更新列表和画布。`dssr_2d` 也复用这一个窗口。
重新分析、切换对象或关闭前，请用 **File → Save layout** 保存手调布局；
这些操作会清除当前编辑历史。
GUI 单击、双击条目复用当前分析。如果修改了分子坐标，或用同名对象替换了
分子，请重新点击 **Analyze**。控制台 `dssr` / `dssr_select` 每次仍重新分析。

## 常用操作

- 左侧下拉框选择结构分类；输入文字筛选条目；单击条目在 2D/3D 中选中。
- 空白处左键拖出蓝框，选择框内中心落入的碱基，并同步到 3D；
  **Shift/Ctrl** 追加，**Alt** 减选。默认鼠标是箭头，不再用鼠标平移画布。
- 拖动碱基本身仍可编辑布局；**B** 自由扫选，**P** 回到框选/编辑。
- **方向键 / WASD** 平移整个画面，**Shift** 加速，不改变碱基坐标；
  **Ctrl+方向键** 微调选中碱基。画布上滚轮缩放，**F** 适应窗口。
- **Ctrl+Z / Ctrl+Y** 撤销、重做坐标编辑。
- 一维序列在画布上方，显示原有字母、链分隔及实际残基编号；点击或拖动
  可选中一段，**Shift** 扩展、**Ctrl** 切换选中。序列条滚轮可横向滚动。
- A 绿、C 蓝、G 棕橙、T 紫、U 红；只给字母着色，圆点及白底保持统一。
- **Gel** 开关果冻效果；**File** 菜单里保存布局、导出图片、复制 DBN。
- **Options** 里调整编号、额外配对、字母颜色和 3D 同步。
- 右侧 **− / ×** 收起/隐藏 2D，左侧列表会展开；顶部 **2D** 恢复原来的
  坐标、缩放和撤销历史。整个 GUI 窗口也支持最小化。

隐藏 2D 面板不会删除布局；关闭整个 GUI 或重新分析仍会清除编辑历史。

删掉了属性条件查询、完整 JSON 浏览/导入导出、批量自动建选区和配色、
网格吸附、跳到编号，以及重复的第二窗口设置。核心结构检测、19 类结构选择、
2D 布局与编辑、扫选和 3D 联动保留；控制台结构选择/碱基块/序列命令保留。
